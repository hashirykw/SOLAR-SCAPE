SolarScape Solutions — website
==============================

Six pages, each one self-contained (styles, scripts, logo and rendered images are inside the file):

  index.html     Home: SOLAR preloader, scroll-driven 3D villa with panel installation, live monitor
  about.html     Story, mission / vision / values, milestones, leadership, offices
  services.html  Plan / Build / Care services, inverter comparison, process, FAQ
  projects.html  House of Italia 50 kW, FOX ESS distributorship, sectors, clients, news
  savings.html   Savings estimator, month-by-month generation, net metering diagram
  contact.html   Contact lines, WhatsApp consultation form, 4 offices, quick answers

DEPLOY
  Keep all six files together in one folder (no subfolders).
  Vercel: upload to a GitHub repo root, import it, Framework preset "Other", no build command.
  Netlify: drag this folder onto app.netlify.com/drop.
  GitHub Pages: push to the repo root and enable Pages on the main branch.

NEEDS INTERNET
  Fonts (Google Fonts), GSAP, Lenis and Three.js load from public CDNs.
  Stock photos load from Unsplash; team photos and client logos load from solarscape.pk.
  If any photo fails, a designed fallback shows instead.
